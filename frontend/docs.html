What is ShinyLuck.

ShinyLuck is a fully on-chain casino on Somnia where the house is a quorum of autonomous AI agents. Every roll, every reel stop, every wheel result is the keccak256 of three numbers anyone can audit — server seed, client seed, and the future blockhash. Money flow is pull-payment; the contract never sends in a callback.

Six games, one contract.
Crash, Slots, Dice, Plinko, Mines, Roulette — all settle through Casino.sol. One bankroll, one max-bet cap (1% of free bankroll), one circuit breaker.
Sub-second finality.
Somnia's ~1.2s block time means your bet is on-chain before the dice finish rolling. No "pending" screens.
Self-custodial.
Funds live in your wallet. The contract escrows stake + max payout only between place and settle, then credits pull-payment for winnings.

Connect and play in 60 seconds.

  1. Click "Connect Wallet" in the top-right. MetaMask, Rabby, OKX, Coinbase Wallet, and any EIP-1193 wallet works.
  2. Switch to Somnia testnet (Shannon). Chain ID 50312. The connect modal auto-adds it if missing.
  3. Get STT from testnet.somnia.network/faucet.
  4. Pick a game. Set your stake, hit place bet. The receipt opens when the reveal-bot settles (≈ 4 blocks).

Supported wallets.

Any EIP-1193 injected provider works. We've tested MetaMask, Rabby, OKX Wallet, and Coinbase Wallet on desktop; MetaMask Mobile and Rabby Mobile via WalletConnect on phones. The frontend uses ethers v6 + the SDK in frontend/lib/shinyluck-sdk.js.

Getting STT testnet tokens.

STT is the gas + bet token on Shannon (Somnia testnet). Drip from testnet.somnia.network/faucet; 0.5 STT per request is plenty for hundreds of small bets. On mainnet the symbol becomes SOMI.

Crash.

Bustabit-style multiplier curve. You pre-commit an auto-cashout in [1.01×, 100×] and stake. The contract uses keccak256(serverSeed || clientSeed || blockhash || nonce) to derive a crashPoint with a 1-in-33 instant-crash baked in (matches the audited Bustabit formula). 3% house edge.

  • Win: autoCashout ≤ crashPoint → payout = stake × autoCashout.
  • Lose: autoCashout > crashPoint → stake forfeited.
  • Per-bet max payout is reserved up-front in lockedReserve; the contract never over-commits the bankroll.

Slots.

3 reels × 7 symbols. Symbol 0 is the jackpot. Triple-jackpot pays 50×; triple-regular 8×; any pair 1.8×. Empirical RTP ≈ 0.947 → 5.3% house edge. Slot theme (cosmetic only) is rotated by the House Manager Agent every 24 hours.

Dice.

Pick a threshold in [2, 98] and a direction (over / under). Roll = randomness mod 100 + 1. Payout multiplier = (10000 − edge) / (winChance × 100). 1% house edge.

Plinko.

16 rows × 17 slots; ball path = 16 bits of randomness (one per peg row). Three risk tiers: low (max 16×), medium (max 110×), high (max 1000×). Tables match standard Stake-style multipliers; 1.5% house edge baked into symbol weights.

Mines.

5×5 grid. Pick the number of mines in [1, 24]; the House Manager pre-commits the seed before you place, but mine positions are only locked in when the seed is revealed (≥ 4 blocks after place). Multiplier scales as ∏ (25-i)/(25-mines-i) × (1 − edge); 100× cap. 1.2% house edge.

  • Open cell: if it's a mine, the round busts (stake forfeited). Otherwise the multiplier compounds.
  • Cashout at any time after opening ≥ 1 cell.
  • Page refresh during a round is safe — frontend reconstructs state from minesState(betId).

Roulette.

European single-zero wheel. 10 bet kinds — straight (35:1), red/black/even/odd/1-18/19-36 (1:1), dozens (2:1). Result = randomness mod 37; multiplier 36 for straight, 3 for dozen, 2 for the others. 2.70% house edge.

Architecture · the agent quorum.

Every settled bet emits a BetSettled event. The AgentQuorumVerifier contract independently asks 4 Somnia LLM Inference workers to re-derive the same keccak256; their signatures are recorded as a QuorumResult event. Money never depends on the quorum signal — randomness is on-chain via blockhash. The quorum is a defence-in-depth liveness check on the agent layer.

JSON API Agent.

Fetches JSON from public endpoints and extracts specific fields. Reserved for v2 oracle workloads (price feeds, external entropy sources). Not in the money path in v1.

LLM Inference Agent.

String-in / string-out inference using qwen3-30b. Used by AgentQuorumVerifier for the 3-of-4 redundancy check, and by the HouseManager cron for narrating its decisions (recordReasoning events). Slot themes are also generated here.

Parse Website Agent.

HTML → structured data scraper. Reserved for v2 (external tournament feeds, social leaderboards). Not yet bound to any v1 contract.

House Manager Agent.

Autonomous cron that:

  • Resizes per-game max-bet to 1% of free bankroll every 5 minutes.
  • Activates BonusMode (house edge × 0.5) when bankroll grows > +10% in an hour.
  • Pauses games when bankroll falls > −20% in an hour (circuit breaker baked into Casino.sol too).
  • Rotates the slot theme every 24 hours via triggerThemeRotation.
  • Logs every decision on-chain via recordReasoning(string) events.

JS SDK.

The frontend SDK is published under frontend/lib/shinyluck-sdk.js. Embed any ShinyLuck game in a dApp:

// import the SDK
import { ShinyLuck, CHAINS } from "./lib/shinyluck-sdk.js";

const sl = new ShinyLuck({
  casino:   "0x8B43…E219",
  registry: "0x0947…E21a",
  network:  CHAINS.somniaTestnet,
});
await sl.connect();
const { betId, txHash } = await sl.placeCrash(2.0, "0.1");
const settled = await sl.waitForSettle(betId);
if (settled.won) console.log("+", settled.payout);

Events & webhooks.

All public state changes are emitted as Solidity events on the Casino contract:

  • BetPlaced(betId, player, game, amount, clientSeed, commitBlock, seedIdx, params)
  • BetSettled(betId, player, game, won, payout, randomness, serverSeed, clientSeed, blockHash, nonce, resultData)
  • BetRefunded(betId, player, amount, reason) — emitted when the blockhash window expires.
  • WithdrawalCredited / WithdrawalClaimed — pull-payment ledger.
  • BonusModeActivated / ReasoningLog — HM Agent traces.
  • QuorumResult — AgentQuorumVerifier signers' agreement level.

Provably fair · how the math works.

For every bet, randomness = keccak256(serverSeed ‖ clientSeed ‖ blockhash(commitBlock + 3) ‖ nonce). The server seed's hash is committed before any bet binds to its slot; the blockhash is unknowable at commit time and only finalises 3 blocks later. The browser-side verifier on the Provably Fair page re-derives this exactly and compares against the on-chain value.

Audit / verification.

The Casino contract on the explorer has its source verified. The CommitReveal library matches the formulation above (single file, ≈ 70 lines). Bug bounty: anything that lets a player or the operator deviate from the published RTPs is in scope; report to security@shinyluck.gg.
